# مِرسال — Mirsal

## المرحلة الأولى — Android APK

هذه النسخة هي تحديث المرحلة الأولى من مِرسال:

- تطبيق Android مستقل.
- يعمل بدون خادم وبدون صلاحية INTERNET.
- AES-256-GCM + PBKDF2-SHA-256.
- منع لقطات الشاشة ومعظم التقاط الشاشة عبر `FLAG_SECURE`.
- تحميل ملفات التطبيق محليًا باستخدام `WebViewAssetLoader`.
- لا يعتمد GitHub Actions على وجود `gradlew` داخل المستودع؛ يتم تجهيز Gradle تلقائيًا أثناء البناء.
- إنشاء APK Debug تلقائيًا من GitHub Actions.

## بناء APK من GitHub

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. افتح تبويب **Actions**.
3. اختر **Build Mirsal APK**.
4. اضغط **Run workflow**.
5. بعد اكتمال البناء افتح الـ Artifact باسم `mirsal-debug-apk` لتحميل APK.

يمكن أيضًا إنشاء البناء تلقائيًا عند دفع Tag يبدأ بـ `v` مثل `v1.0.0`.

> ملاحظة: نسخة Debug مناسبة للاختبار. إصدار Play Store يحتاج لاحقًا إلى إعداد توقيع Release ومفاتيح GitHub Secrets.

## المرحلة الثانية — تحديثات هذه النسخة

- **تشفير الملفات**: يمكن الآن تشفير/فك تشفير أي صورة أو مستند (وليس النصوص فقط)، عبر تبويب "📁 ملف". الملف المشفّر يُحفظ بامتداد `.mirsal` ويحتفظ باسم الملف الأصلي.
- **إصلاح أمني (توافقية)**: عدد تكرارات PBKDF2 كان ثابتًا في الكود؛ أصبح الآن يُحفظ داخل كل رسالة/ملف مشفّر، بحيث لا يكسر أي تحديث مستقبلي للأرقام الرسائلَ أو الملفات المشفّرة سابقًا. رسائل الإصدار القديم (`MSL1`) ما زالت تُفك بشكل صحيح.
- **إصلاح أمني**: مسح تلقائي لمحتوى الحافظة (clipboard) بعد 45 ثانية من نسخ المفتاح أو الناتج.
- **إصلاح أمني**: مسح تلقائي لحقول الرسالة/المفتاح/الملف المختار بعد دقيقتين من الخمول.
- **دعم اختيار وحفظ الملفات فعليًا على أندرويد**: أُضيف `onShowFileChooser` (لم يكن مفعّلاً سابقًا، فكان حقل اختيار الملف لا يفتح شيئًا) وجسر JavaScript↔Kotlin يحفظ الملف الناتج في مجلد التنزيلات عبر `MediaStore` دون أي صلاحية تخزين إضافية.
- تم رفع `minSdk` إلى 29 (Android 10) لأن `MediaStore.Downloads` يتطلبها؛ هذا يبقي التطبيق بلا أي صلاحيات في `AndroidManifest.xml`.
